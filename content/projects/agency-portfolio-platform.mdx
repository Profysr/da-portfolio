## The Brief

Build a portfolio that feels like a product — not a template. Interactive, performant, memorable.

## Technical Highlights

- **WebGL Globe (cobe)** — 10k+ particles, custom shaders for glow trails, runs at 60fps on mobile
- **Contribution Heatmap** — Deterministic 52×7 grid, seeded PRNG, zero API calls
- **Glassmorphism System** — CSS variables for theme tokens, backdrop-filter fallbacks
- **Motion Animations** — Framer Motion for layout animations, scroll-triggered reveals
- **Edge Caching** — Static export to CDN, `<100ms TTFB` globally

## Performance

- Lighthouse: 98/100 Performance
- Bundle: `<150KB` gzipped (React + Motion + Tailwind)
- Zero layout shift

## The Problem

N+1 queries kill API performance. Existing profilers are either too heavy (PySpy) or too shallow (Django Debug Toolbar).

## Solution

A lightweight middleware that:

1. **Intercepts** every ORM query via SQLAlchemy event hooks
2. **Analyzes** query patterns using AST parsing — detects N+1, missing indexes, cartesian products
3. **Visualizes** results as interactive flame graphs in a React dashboard
4. **Integrates** with FastAPI/Starlette/Django via one-line middleware

## Usage

```python
from da_profiler import ProfilerMiddleware

app.add_middleware(ProfilerMiddleware, sample_rate=0.1)
```

Visit `/profiler` to see live query analysis.
